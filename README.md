# PetRoutine

> Персоналізований цифровий органайзер та трекер догляду за домашніми тваринами для всієї родини.

---

## Проблема та Рішення

**Назва проєкту:** PetRoutine  
**Проблема:** Через унікальні потреби тварин, тривалі періоди розлуки та відсутність синхронізації між членами родини, графіки догляду порушуються, а рутинні дії (наприклад, годування чи вигул) або забуваються, або дублюються кількома людьми поспіль («Я погодував, і ти погодував»).  
**Рішення:** Застосунок діє як спільний сімейний цифровий органайзер, що містить єдину базу даних профілів тварин, систему автоматичних нагадувань про критичні процедури та real-time фіксацію щоденних активностей для всієї родини.  
**Цільовий користувач:** Власники домашніх тварин (особливо родини з кількома улюбленцями або ті, хто часто залучає ситтерів та родичів до догляду), яким потрібен надійний інструмент для контролю здоров'я та синхронізації щоденної рутини вихованців.

## API Design

### 1. POST /api/v1/pets/{petId}/activities

**Призначення:** Зафіксувати виконання рутинної дії (наприклад, годування або вигул) членом родини.

**Request Header:** `Authorization: Bearer <JWT_TOKEN>`

**Request Body:**

```json
{
  "activityType": "FEEDING",
  "performedAt": "2026-05-31T20:15:00Z",
  "notes": "Дав 50г сухого корму для цуценят"
}

```

**Response 201 Created:**

```json
{
  "id": 452,
  "petId": 12,
  "activityType": "FEEDING",
  "performedAt": "2026-05-31T20:15:00Z",
  "performedBy": "Олександр",
  "notes": "Дав 50г сухого корму для цуценят"
}

```

* **Response 400 Bad Request:** Якщо `activityType` не підтримується або `performedAt` вказує на майбутній час.
* **Response 403 Forbidden:** Якщо користувач не належить до родини, яка володіє цією твариною.
* **Response 404 Not Found:** Якщо `petId` не існує в системі.

---

### 2. GET /api/v1/pets/{petId}/activities/today

**Призначення:** Отримати список усіх виконаних активностей по конкретній тварині за поточну добу (для перевірки родиною).

**Request Header:** `Authorization: Bearer <JWT_TOKEN>`

**Response 200 OK:**

```json
[
  {
    "id": 450,
    "activityType": "WALKING",
    "performedAt": "2026-05-31T07:30:00Z",
    "performedBy": "Ганна",
    "notes": "Гуляли 40 хвилин у парку"
  },
  {
    "id": 452,
    "activityType": "FEEDING",
    "performedAt": "2026-05-31T20:15:00Z",
    "performedBy": "Олександр",
    "notes": "Дав 50г сухого корму для цуценят"
  }
]

```

## Тестова стратегія

| ID | Назва | Given | When | Then | Тип |
| --- | --- | --- | --- | --- | --- |
| **TC-01** | Успішне логування активності | Авторизований користувач, що належить до родини власника тварини | `POST /api/v1/pets/12/activities` з валідним `activityType` | **201 Created**, запис з'являється в базі даних з ID користувача. | Integration |
| **TC-02** | Спроба логування для чужої тварини | Авторизований користувач, який не належить до родини власника тварини | `POST /api/v1/pets/12/activities` | **403 Forbidden**, операція відхилена, дані ізольовані. | Integration |
| **TC-03** | Валідація некоректного типу активності | Авторизований користувач | `POST /api/v1/pets/12/activities` з `"activityType": "FLYING"` | **400 Bad Request**, тіло відповіді містить опис помилки валідації. | Unit |
| **TC-04** | Отримання списку активностей для нової тварини | Авторизований користувач, у тварини якого ще не було активностей за сьогодні | `GET /api/v1/pets/12/activities/today` | **200 OK**, повертається порожній масив `[]`. | Integration |
