# PetRoutine

## Проблема
Через унікальні потреби різних домашніх тварин та тривалі періоди розлуки з ними, господарям буває важко тримати в голові всі деталі щоденного догляду, через що специфічна рутина та графіки обов'язкових процедур легко забуваються.

## Рішення
Застосунок діє як персоналізований цифровий органайзер для домашніх улюбленців. Він вирішує проблему забудькуватості завдяки двом ключовим інструментам:
1. **Картка тварини (База даних):** Зберігає повний профіль улюбленця в одному місці (вид, порода, вік, стать, статус стерилізації, алергії, точне дозування корму, тривалість прогулянок та особливості щоденної рутини).
2. **Система сповіщень:** Автоматично нагадує про критично важливі періодичні процедури, як-от планові щеплення, чищення зубів, обробка від паразитів чи візити до ветеринара.

Завдяки цьому власник може миттєво відновити правильний догляд за твариною навіть після довгої перерви, а також легко передати актуальну інструкцію іншій людині (наприклад, ситтеру), яка тимчасово доглядає за улюбленцем.

## Цільовий користувач
Власники домашніх тварин (особливо тих, що мають кілька улюбленців або змушені часто подорожувати й залишати тварин наглядачам), яким потрібен надійний помічник для систематизації догляду та контролю за здоров'ям вихованців.
